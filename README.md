# 박미정 연구 홈페이지

의존성 없이 실행되는 반응형 정적 홈페이지입니다.

## 미리보기

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다. 로컬 서버가 필요하면 이 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 주요 파일

- `index.html`: 페이지 구조, 소개 문구, 검색 노출 메타데이터
- `styles.css`: 색상, 타이포그래피, 반응형 레이아웃
- `data.js`: 한·영 논문 제목과 초록, 학위논문, 프로젝트, 경력, 학력, 수상, 저서 데이터
- `script.js`: 한글·영문 전환, 논문 검색·연도 필터·초록 상세, 모바일 메뉴, 탭
- `assets/park-mijeong-profile.jpg`: 대표 사진
- `assets/knue-campus-main.jpg`: 첫 화면 학교 사진
- `assets/knue-campus-gate.jpg`: 연락처 영역 학교 사진

콘텐츠는 `data.js`에서 수정할 수 있습니다. 사진을 교체할 때는 같은 파일명과 비슷한 가로세로 비율을 유지하면 레이아웃이 안정적으로 유지됩니다. 언어 선택은 방문자의 브라우저에 저장됩니다.

## 배포

폴더 전체를 GitHub Pages, Netlify, Cloudflare Pages 등 정적 호스팅에 업로드할 수 있습니다. 별도 빌드 명령은 필요하지 않습니다.

## 향후 콘텐츠 업데이트

- 논문: 현재와 같은 열 구조의 엑셀에서 새 논문을 추가하거나 기존 행을 수정하면 됩니다. 업데이트할 때 `번호`, 한글·영문 제목, 저자, 학술지, 연도, 권·호, 페이지, 초록, DOI 또는 원문 링크를 유지합니다.
- 경력·프로젝트·수상·저서: `data.js`의 해당 목록만 수정하면 디자인과 기능은 그대로 유지됩니다.
- 같은 직책의 연속된 임기는 한 항목으로 합치고, 직책이 달라지면 별도 항목으로 기록합니다.
- 최신 엑셀과 변경된 경력 목록을 연구 홈페이지 메이커에게 전달하면 기존 레이아웃을 다시 만들지 않고 데이터만 갱신할 수 있습니다.
